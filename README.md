# UserFinder:
User Finder is a simple web project that helps users find people by searching their names.
It displays user info in easy-to-read cards.

#Features:
1. Search for users by name.
2. Display user details in cards
3. Show a message if no users found
4. Simple and user-friendly design

#Tech Used:
1.HTML
2.CSS
3.JS

#How to use:
Open the User Finder website.
Type a name in the search box.
View the matching users.
If no user matches your search, a message will appear.

#Purpose:
This project was created to practice JS ,DOM manipulation, event handling,localStorage and Searching through data.
